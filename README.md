## 🛠 Tech

- **100% HTML + CSS.** Zero JavaScript — fully GitHub Pages compatible.
- Mobile menu, FAQ accordion and all animations are pure CSS (checkbox hack + `<details>`).
- All decorative artwork (mandala, toran, diyas, chakra, ticket, barcode) is generated in CSS — **no image files**, so the site loads instantly.
- Fonts: Rozha One, Cinzel, Poppins (Google Fonts).
- Fully responsive + respects `prefers-reduced-motion`.

## 🚀 Enable GitHub Pages

1. Go to **Settings → Pages**
2. Under *Build and deployment* → **Source: Deploy from a branch**
3. Branch: **`main`**, folder: **`/ (root)`** → **Save**
4. Live in ~1 minute at `https://TJ-zip.github.io/arise-entertainments/`
